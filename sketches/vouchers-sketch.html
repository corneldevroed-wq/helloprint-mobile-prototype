My account: Vouchers

Cornel chose A (2026-11-19): built as prototype/vouchers.html.

What changes

  • New menu item “Vouchers” under Complaints, in the account card, the header’s account menu and the mobile account sheet. It needs a new icon (a tag, Material “sell”, as an SVG in design-system/icons).
  • New page vouchers.html listing every personal discount code: what you get, the code, valid until, and its status (Available, Used, Expired). A code you can use gets a Copy button. A used one says on which order.
  • From a complaint: one extra grey line, “From complaint CMP-1042 · Roller Banner damaged on arrival”, linking to the case.
  • Stays: you still enter a code in the cart under “Add discount code”, as today. VIP status (−4%) is automatic, so it isn’t a voucher here.
  • The demo data is ours: 3 codes to use (one from a complaint), 2 used (one from a complaint), 1 expired.

My pick: B. A voucher is about what it’s worth, so the codes you can use get a card with the value big and Copy right next to the code. Used and expired drop to a quiet table under them, where they don’t get in the way. A is the list page of Orders, Invoices and Quotes: very consistent, but with 3–6 codes the filters and search are overkill and the value is lost in a column. C (setting rows as Personal details) is calm but flat: an available €20 looks the same as an expired €5.
