Pages from a prompt: step 1, a category page

The test: the Hospitality category page, written as an md spec and built only from the blocks of the category template (promotional.html). First try was the home as template; Cornel (11-14): the category template holds much more, and this is an ordinary category page, not a marketing page. The special marketing page comes next, from Figma, with another subject.

How it works

1 · Brief

One line or a short md

"Category page Hospitality, en-ie: bars, restaurants, hotels, events."

2 · Generator (skill)

Writes hospitality.md

Picks blocks from the template, writes the copy, picks real products from live, writes image prompts. Never HTML or CSS.

3 · Renderer

One page, every md

category.html?page=hospitality builds the page with the design-system classes. Mobile and desktop from the same md.

4 · Check

Ready or not

Tokens only, 8px grid, block rules (title ±35 chars…), no helloprint.com links, noindex, measured at 390 and 1512.

Where the page lives

What the generator writes, and what you and the team read and change.

A · One md file per page My pick

Front matter (theme, audience, tone) + one ## block section per block. Readable for marketers, easy to change by hand, the rules sit as comments next to each block. Small parser in the renderer.

B · JSON per page

Strict and easy to validate, but nobody wants to edit it by hand, and copy in JSON is hard to read. Fine as the parser's output, not as the source.

C · Only the brief, generated on the fly

No file in between: each render asks the model again. Different every time, nothing to review or version. Not for a page we want to hand over.

The category template's blocks

From prototype/promotional.html. Every block except hero and seo can repeat; a block with a tab: gets a section tab.

hero

.hero: crumbs, h1 = the category name, intro 1–2 sentences.

tabs

.tabs, sticky. Built from the blocks with tab: + id:, never written by hand.

feature

.plp-feature: promo card + exactly 6 tiles (3 rows of 2 on desktop). Card title ±35–60 chars, no text in the image.

products

.types .product: 5 or 10 (5 per row on desktop). Live products, live "N pieces for €X", badge only from live.

categories

.plp-cats: 4 or 5 grey tiles in one row (.four / .five); swipe row on mobile.

seo

.about.cat-about: 1–2 open paragraphs + 2–4 folded questions, 250–500 words.
