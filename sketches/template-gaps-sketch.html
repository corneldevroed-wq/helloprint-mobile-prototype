Filling the template gaps with what we have

The GAA page showed 7 gaps. Each one closes with a variant or modifier of a component that is already in the UI library: no new blocks. Per gap the options side by side, my pick marked; the orange line under each option names what changes in the library. Copy from the GAA board; grey blocks where the images go.
